Этот репозиторий предлагает решение для бэкенда, которое использует NestJS, Swagger и AmoCRM API.

## Требования

- **Node.js**: Убедитесь, что Node.js установлен.
- **PNPM**: Рекомендуется использовать как менеджер пакетов.
- **Аккаунт AmoCRM**: Требуется для доступа к AmoCRM API.

## Установка

### Клонирование репозитория

Клонируйте репозиторий и перейдите в каталог проекта:

```bash
git clone https://github.com/volveezz/amo-crm-showcase.git
cd amo-crm-showcase
```

## Конфигурация

1. **Переменные окружения:**  
   Переименуйте `.env.example` в `.env` или создайте новый файл `.env` на основе предоставленного примера.

2. **Вставьте токены API, эндпоинты и укажите точное имя хоста и порт**:  
   При настройке интеграции с AmoCRM убедитесь, что вы указали точное имя хоста и номер порта для правильной работы API.

## Использование

Чтобы запустить проект, выполните следующую команду:

```bash
pnpm install && pnpm build && pnpm start:prod
```
